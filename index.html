  • SME Anchor

    AI operations platform linking Sales, Planning, and Procurement for manufacturing MSMEs through real-time WhatsApp.

    Project Demo ↗
    • Connects Sales → Planning → Procurement via real-time WhatsApp using Next.js, TypeScript, PostgreSQL, Prisma, and Neonize (deterministic JID-to-supplier mapping).
    • Automates 18 procurement lifecycle stages (supplier discovery, RFQ generation, quotation extraction, ranking, human-in-the-loop approval, PO creation, shipment tracking) with AI quotation comparison and margin estimation.
    Runner-up Coimbatore Innovation Hackathon (CIH’26) 18 Lifecycle Stages
    TypeScript · Python · Next.js · PostgreSQL · Prisma ORM · Neonize

  • Q-Catalyst

    Mechanism-aware AI platform for PETase enzyme engineering and combinatorial mutant prioritization.

    Live Demo ↗
    • Combines ESM-2 embeddings, ESM-1v zero-shot scoring, uncertainty estimation, and catalytic-site structural validation.
    • Ridge Regression & XGBoost on ESM-2 features achieved Spearman 0.5304 (p = 5.5×10⁻⁶) on a leakage-controlled held-out set of 65 combinatorial mutants.
    • Includes PySCF (DFT & active-space CASCI) catalytic-site calculations and explicit-solvent OpenMM molecular dynamics validation for WT IsPETase (5XJH), FAST-PETase (7SH6), and engineered candidates.
    Leakage-Controlled Test Set (N=65) Spearman ρ = 0.5304
    ESM-2 · ESM-1v · PySCF (DFT/CASCI) · OpenMM · XGBoost · FastAPI · RDKit

  • SONAR-INTEL

    Evidence-prioritized ghost net triage and detection system from acoustic side-scan sonar.

    Live Demo ↗
    • Triage pipeline across 9,356 side-scan sonar tiles (Lee denoising, standardized tiling, reconstruction checks) separating ghost nets from rocks, cables, and fish schools for human review.
    • Distilled a YOLO11M teacher into a YOLO11N student (PyTorch, Ultralytics) for edge inference, reaching 84.8% mAP@50, 90.2% precision, and 81.7% recall (epoch 21).
    • Edge-to-backend analyst confirm / reject / export workflow with deterministic evidence ranking.
    9,356 Sonar Tiles Triaged 84.8% mAP@50 · 90.2% P · 81.7% R
    PyTorch · Ultralytics YOLO11 · Knowledge Distillation · Edge AI · OpenCV

  • FraudSentinel AI

    Hybrid fraud detection and explainability system operating over real-time transaction pipelines.

    Live Demo ↗
    • Hybrid pipeline combining XGBoost, Isolation Forest, ChromaDB RAG, and local Ollama LLM inference across 284K+ transactions.
    • Achieved 93.3% recall at 0.03% FPR via threshold-optimized ensemble scoring.
    • Serves FastAPI REST APIs delivering deterministic fraud explanations in < 1 second with automated Recall, PR-AUC, and FPR evaluation.
    284K+ Transactions Stream 93.3% Recall @ 0.03% FPR
    XGBoost · Isolation Forest · ChromaDB RAG · FastAPI · Ollama · SHAP
